# BridgeTopia Extension

## 是什麼?
Chrome 擴充：把你在 BBO（Bridge Base Online）打過的牌，送進 BridgeTopia。

這個擴充不讀你的 cookie（manifest 裡沒有 `cookies` 權限），也不會把你的 BBO 帳密或 session 交給任何伺服器，請安心使用。

## 安裝

1. 解壓縮這個 zip，放到一個**你不會去刪的**資料夾（Chrome 每次啟動都要從那裡讀）
2. Chrome → 網址列輸入 `chrome://extensions` → 右上角開啟「**開發人員模式**」
3. 左上角按「**載入未封裝項目**」→ 選第 1 步解出來的資料夾

只有 Chrome 系（Chrome / Edge / Brave）。Firefox 目前不支援。

## 第一次設定

**BBO 帳號**：點擴充圖示，popup 上填一次就記住。

**匯入的目的地**：輸入伺服器 URL (請跟作者拿，填完後不用改)

1. 點 popup 右上角的 **⚙**
2. 填 origin ，例如 `https://example.ts.net`。
3. 按「存起來」→ Chrome 會跳出對話框問這個網域的權限，**按同意**

換一台電腦要再做一次第 3 步：位址會跟著 Chrome 帳號同步，**權限不會**。

**還有一件事：匯入靠的是你 BridgeTopia 的登入狀態。** 同一個 Chrome 裡開著
BridgeTopia、登入著就好（不用填 token，也不用讓那個分頁保持開啟）。沒登入的話匯入會說「尚未登入」。

## 用法

先留著一個**登入中的 `bridgebase.com` 分頁**（哪一頁都可以，不用是 myhands），然後：

1. 點擴充圖示 → 選日期範圍（預設最近 7 天，也有 30 天 / 本月的快捷）→ 按「**查詢這段有哪些
   session**」
2. 找到的每一場一個勾選框。**最新那場有新牌的預先勾好**，其他自己加勾。已經全部下載過的
   會標「已下載」並停用
3. 按「**下載勾選的 N 副**」→ 抓回來的牌先**存在你的瀏覽器本機**，還沒對外連線
4. 按「**匯入到 BridgeTopia**」→ 這一步才會連你的伺服器

**下載中可以直接關掉 popup**，工作是交給那個 BBO 分頁做的，關了照樣跑完。回來再開 popup
會接著顯示現在抓到第幾副。

查詢結果也留著：關掉再開不會重新問 BBO 一次，清單上會標「查詢於 HH:MM」。

## 要知道的兩件事

**下載過但還沒匯入的牌存在瀏覽器本機。** 匯入成功才清掉。所以中途關掉 Chrome 不會掉，
但按「清除」會丟掉它們，要重新下載。

**匯入前不會對外連線。** 查詢和下載都只跟 `bridgebase.com` 講話，按了「匯入」才連伺服器。

## 出問題要回報

`chrome://extensions` → 這個擴充 → 「Service Worker」/「錯誤」，把裡面的訊息附上。
popup 的錯誤訊息在關掉 popup 之後就沒了，先截圖。
